# boussole

Site de mon activité professionnelle : Bilan de compétences et coaching.

## Démarrer un environnement de développement convivial

Pour un développement fluide, vous pouvez utiliser **Node.js** et un outil comme **live-server** qui recharge automatiquement la page lors des modifications :

```bash
npm install -g live-server
live-server
```

Cela ouvre le site dans votre navigateur et actualise la page à chaque changement.

Le répertoire contient désormais :

- `index.html` — la page principale du site
- `css/style.css` — les styles pour un rendu sérieux et moderne
- `js/script.js` — un petit script pour des interactions dynamiques

N'hésitez pas à adapter le design et le contenu pour refléter votre identité professionnelle.
